# LAYOVER

Offline Texas Hold'em. Chips only. No account.

## Play on a phone

Best: open this preview link in Safari (GitHub itself will not run the game):

https://htmlpreview.github.io/?https://github.com/glphealthtracker/layover-holdem/blob/main/index.html

Then tap Share → Add to Home Screen.

If `index.html` is not in this repo yet, download `layover.html` from the Grok chat and AirDrop it. On iPhone: Files → tap the file → Share → Open in Safari.

You are the bottom seat. Fold / Check-Call / Raise.
